Add a hierarchical fuzzy MCDA evaluation engine for parcel analyses. Analyses now carry an evaluation profile (only `izhs` for now) and are scored by fuzzy normalization plus weighted hierarchical aggregation instead of a random placeholder. Every evaluation is persisted per level (clusters, subclusters and metric contributions, including the applied membership function and its parameters) and can be retrieved via `GET /api/v1/analysis/{id}/evaluation`. Missing metrics are handled by renormalizing weights over the readings that are actually available.
