Add API endpoints for map layers. `GET /api/v1/analysis/{id}/metrics` lists the metric snapshot references recorded for an analysis, and `GET /api/v1/infrastructure/objects?category=&metrics_id=` returns the objects behind an infrastructure metrics snapshot as a GeoJSON FeatureCollection (buffer and parcel are taken from the snapshot, so the objects match the metric's spatial scope). The infrastructure categories endpoint now also returns a human-readable label per category.
