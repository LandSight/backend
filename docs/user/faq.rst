FAQ
===

Частые вопросы от пользователей.

- **Как запустить локально?** — Установите зависимости через ``make install`` и используйте команду из раздела :doc:`getting-started`.
- **Где посмотреть доступные функции?** — Список возможностей в разделе :doc:`features`.
- **Что делать при ошибке запуска?** — Проверьте версии ``uv`` и ``make``, затем обратитесь к разделу для разработчиков или поддержке.

Раздел будет пополняться по мере появления новых вопросов.
