Getting Started
===============

Быстрый старт для запуска приложения локально.

1. Установите системные зависимости: ``uv`` и ``make``.
2. Клонируйте репозиторий и установите зависимости:

   .. code-block:: bash

      git clone https://github.com/LandSight/backend.git
      cd backend
      make install

3. Запустите приложение (дополнить конкретной командой по мере готовности сервисов).
4. Откройте документацию по функциям в разделе :doc:`features`.

Если возникли сложности, смотрите :doc:`faq`.
