Key Features
============

Краткий обзор основных возможностей приложения.

- Автоматический сбор и агрегация открытых пространственных данных по земельным участкам.
- Анализ характеристик участков (геометрия, юридический статус, экологический контекст, инфраструктура).
- Формирование понятных отчётов и показателей на базе собранных данных.
- Возможность локального запуска для экспериментов и пилотов.

Расширенные сценарии и примеры использования будут добавляться по мере развития продукта.
