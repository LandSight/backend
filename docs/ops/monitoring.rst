Monitoring and Alerts
=====================

Наблюдаемость приложения.

- Метрики и дашборды: какие показатели собирать (health, latency, error rate, использование ресурсов) и где смотреть.
- Логирование: форматы и уровни, маршрутизация логов, рекомендации по фильтрам.
- Алерты: пороговые значения, каналы уведомлений, ответственность за реакцию.
- Health-checks: эндпоинты для проверки состояния и готовности сервисов.

По мере выбора инструментов (Prometheus/Grafana/ELK и т.д.) добавьте конкретные конфигурации и примеры.
