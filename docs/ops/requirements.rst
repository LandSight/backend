System Requirements
===================

Минимальные требования для развертывания.

- Python 3.14 и совместимый интерпретатор.
- ``uv`` для управления зависимостями и виртуальным окружением.
- Доступ к необходимым внешним сервисам (БД, очереди, хранилища) — уточнить по мере подключения инфраструктуры.
- Инструменты сборки документации и тестов при необходимости (группы зависимостей ``docs`` и ``test``).

Точные версии и рекомендуемые ресурсы (CPU/RAM/Disk) будут уточняться после выбора целевых окружений.
