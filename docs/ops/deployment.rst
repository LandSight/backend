Deployment
==========

Общий процесс развертывания.

1. Подготовьте окружение: установите системные зависимости и создайте виртуальное окружение через ``make install`` или ``uv``.
2. Настройте конфигурацию окружения (переменные, секреты) согласно :doc:`configuration`.
3. Выполните миграции/инициализацию данных (описать конкретные команды при добавлении).
4. Соберите и запустите сервисы (systemd/docker — указать точный способ при стандартизации).
5. Проверьте состояние: health-check, логи, базовые сценарии.

Для разных окружений (dev/stage/prod) зафиксируйте отличия в отдельных подпунктах этого файла.
