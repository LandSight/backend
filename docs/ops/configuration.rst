Configuration
=============

Настройки приложения и среды.

- Переменные окружения: вынесите список ключевых параметров (БД, очереди, внешние API). Пока использовать рабочий пример из ``.env.example`` (добавить при наличии).
- Конфигурационные файлы: опишите расположение и формат (например, ``config/*`` или ``pyproject.toml`` для tooling).
- Секреты: храните вне репозитория, используйте менеджер секретов или переменные окружения.

Раздел дополняется по мере появления новых параметров.
