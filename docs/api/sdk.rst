SDK and Examples
================

Примеры интеграции с API.

- Фрагменты кода для Python/CLI или других языков.
- Типичные сценарии: аутентификация, базовые запросы, обработка ошибок.
- Рекомендации по ретраям и лимитам.

Раздел расширяется по мере появления клиентских библиотек и готовых сниппетов.
