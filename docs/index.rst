Land Sight documentation
========================

Land Sight is a software suite that automates the collection, processing, and analysis of spatial data about land parcels using open geodata.
The suite provides clear, user-friendly reports based on the analysis of parcel characteristics such as geometry, legal status, environmental context, and infrastructure parameters.
