Testing
=======

Политика тестирования и организация тестов.

- Фреймворк: ``pytest``.
- Запуск всех тестов: ``make test`` (использует группу зависимостей ``test``).
- Структура каталога ``tests``:

  - ``tests/unit`` — модульные тесты.
  - ``tests/integration`` — интеграционные тесты.
  - ``tests/e2e`` — сквозные сценарии.
  - Общие фикстуры — ``tests/conftest.py``; вспомогательные данные и фабрики — в подкаталогах.

- Именование: файлы ``test_*.py``; имя модуля по возможности совпадает с модулем из ``src``.
- Правила: новое поведение требует тестов; багфиксы сопровождаются регресс-тестами; тесты должны быть детерминированными.
- ``xfail`` используется только для известных и задокументированных проблем.
