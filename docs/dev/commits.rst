Commit Conventions
==================

Правила оформления коммитов (Conventional Commits).

- Формат: ``<type>[optional scope]: <summary>``; при breaking change — ``!`` после типа или scope.
- Основные типы: ``feat``, ``fix``, ``docs``, ``style``, ``refactor``, ``test``, ``chore``, ``build``, ``ci``, ``release``, ``revert``.
- Summary — повелительное наклонение, без точки, до 72 символов.
- Каждый коммит отражает одну логическую изменение и оставляет проект в рабочем состоянии.
- При сложных изменениях добавляйте тело коммита с мотивацией и ключевыми деталями.

Подробности и примеры смотрите в укороченной версии CONTRIBUTING и связанных правилах.
