Code Style and Typing
=====================

Основные соглашения по стилю и типам.

- Базовый стиль — PEP 8, длина строки 120 символов, строки в двойных кавычках.
- Докстринги — формат NumPy: разделы ``Parameters``, ``Returns``, ``Raises``; при необходимости дополнительные секции.
- Все публичные функции и методы должны иметь аннотации типов для аргументов и возвращаемых значений.
- Линтеры: ``ruff`` и ``ty`` конфигурируются в ``pyproject.toml``; используйте ``make check-lint`` и ``make check-fmt`` для проверки.
- Форматирование выполняет ``ruff format``; не правьте формат вручную, если проблему решает автоформаттер.

За деталями и исключениями смотрите конфигурацию в ``pyproject.toml``.
