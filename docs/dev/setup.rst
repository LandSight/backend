Development Setup
=================

Подготовка окружения для разработки.

- Требования: ``uv >= 0.9.0``, ``make >= 4.0.0``, Python 3.14.
- Установка зависимостей:

  .. code-block:: bash

     make install

- Основные группы зависимостей:

  - ``dev`` — полный набор для разработки (документация, тесты, линтеры).
  - ``test`` — только для тестов.
  - ``docs`` — сборка документации.
  - ``lint`` — статический анализ и форматирование.

При необходимости обновить окружение повторите ``make install`` или используйте ``uv sync --group=<name>``.
