Pull Requests
=============

Требования к оформлению и проверкам pull request.

- Один PR — одна логическая задача; делайте изменения минимальными и обозримыми.
- Заголовок кратко описывает суть изменений; описание содержит мотивацию, ключевые пункты и инструкции по проверке.
- Перед открытием PR убедитесь, что выполнены ``make check-lint``, ``make check-fmt``, ``make test``.
- Явно указывайте breaking changes и ссылки на связанные задачи/issue.
- После правок по ревью перезапустите проверки и запросите повторный обзор.
