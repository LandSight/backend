Business Flows
==============

Ключевые бизнес-процессы (заполнить деталями по мере формализации).

Примеры процессов:

- Приём запроса на участок → сбор входных данных → валидация → запуск анализа → формирование отчёта.
- Обновление данных по участку при появлении новых источников или версий геоданных.
- Ручная проверка/апрув результатов анализа и обратная связь в систему.

Добавляйте диаграммы и подробные шаги для каждого процесса по мере документирования.
