Glossary
========

Словарь терминов по предметной области.

- **Участок** — земельный участок, объект анализа.
- **Источники геоданных** — открытые или внутренние ресурсы, откуда загружаются пространственные данные.
- **Отчёт** — итоговый документ с показателями и выводами по участку.
- **Показатели** — вычисленные метрики (геометрия, правовой статус, экология, инфраструктура и др.).
