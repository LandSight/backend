Domain Overview
===============

Краткий контекст проекта.

- Цель: автоматизировать сбор и анализ пространственных данных по земельным участкам на основе открытых источников.
- Результат: отчёты и метрики о геометрии, правовом статусе, экологическом окружении и инфраструктуре участка.
- Пользователи: специалисты, принимающие решения по землеустроительным задачам, и интеграторы, использующие данные в своих системах.

Подробнее о процессах — в разделах :doc:`flows` и :doc:`rules`.
